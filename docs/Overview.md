# Project Overview
>This document is not very useful and should not be read. It's just used for the school project rubric

**Mille** is a C# CLI text editor using regex for syntax highlighting.

## Problem it will solve
Mille will solve the problem that no text editors lets you write all syntax highlighting rules in regex (regular expressions) which is probably the most popular way to select or detect text, as well as existing editors like Emacs requiring lisp which most devs may not know or want to use

## Target Users
Programmers that don’t know lisp and want a terminal text editor which has easy configuration for syntax highlighting rules using regex

## Key features
- Syntax highlighting with regex (customizable) 
- keybinds 
- Line numbers
- Multiple editor file buffers with `Alt-<` or `Alt->`
- Keybind display at the bottom
